# Ohuhu Colors Generator

Aplicación frontend para generar combinaciones aleatorias de colores de las paletas de rotuladores Ohuhu Honolulu.

## Tecnologías

- Vite
- React y TypeScript
- Tailwind CSS
- Material UI

## Desarrollo

```bash
npm install
npm run dev
```

## Estado actual

El repositorio está preparado como base de la V1. La interfaz muestra temporalmente «Hola, mundo» mientras se implementan los datos locales, filtros y generación de colores definidos en `PLANIFICATION.md`.
